# Feature graph implementation and mapping evidence

The feature graph milestone covers the complete mapping from seven 320-value
feature frames to a 961-value noise mask. Its implementation is complete on the
CPU reference and resident Vulkan paths. This does not establish waveform parity
with RTX Voice or resolve the reported muffling and residual static.

`model-graph.json` is generated by `clearwave graph`. It includes every processing
stage, its source connections, dimensions, and the stored shape and axis meaning
of every learned tensor. All 32 tensor lengths are checked against this contract
before network creation. Tensor exports retain the original stored order.

## Static mapping evidence

The reference is the supplied 0.5.12.6 runtime, SHA-256
`c3845f23a9e1859d8a7bb42eb683a2767ecfa3b7f241980d4202655f1c1a1e03`.
The addresses below are relative virtual addresses within that file. Only static
data and instructions were inspected; no vendor library was executed. Runtime
and model files are excluded from the repository and distributions.

| Mapping | Evidence in the reference runtime | Executable behavior |
| --- | --- | --- |
| Three convolution blocks | `0x2d0f5..0x2d173`, `0x2d229..0x2d2a3`, `0x2d357..0x2d3cb` supply channels 16/24/32, time kernel 3, frequency kernel 5, padding 0/2 and stride 1. `0x2a31f..0x2a377` constructs the cross-correlation descriptor. | Shared convolution dimensions; NCHW activations and OIHW filters on both backends. |
| Stored convolution filters | `0x2a9cc..0x2a9f6` and `0x2abe2..0x2ac06` pass output/input/time/frequency dimensions and format 0 to the filter descriptor; loading at `0x27e79..0x27e9d` copies the stored values directly. | No filter-axis conversion or spatial reversal. |
| Activation and normalization order | `0x2acb8..0x2accb` selects activation mode 1 (ReLU); `0x2a6a6..0x2a72b` performs convolution+bias+activation. Calls at `0x2d83b..0x2d8a5` alternate each convolution with normalization. Epsilon at `0x3eb38` is the F32 representation of 0.001. | ReLU occurs before normalization; normalization may produce negative values and has no following ReLU. |
| Noise branch input | `0x2d95b..0x2d96b` takes the original context pointer plus `3 * feature_count` F32 elements. | The noise GRU receives context index 3, aligned with the center of the seven-frame convolution window. |
| Convolution feature permutation | `0x2d8d4..0x2d8e0` invokes `0x25d70`. At `0x25dde..0x25e41`, that helper builds a strided N/H/W/C view over N/C/H/W storage; `0x25e62..0x25ecb` copies into contiguous N/H/W/C order. | CPU transpose and GPU indexed access flatten frequency first with channel innermost. This conversion is required even though the final temporal extent is one. |
| Noise-first concatenation and recurrent chain | `0x2da45..0x2da6a` passes the noise output followed by the permuted convolution output to `0x29e50`; `0x29f50..0x2a0c4` writes the first segment at zero and the second at the first segment's byte length. `0x2da7c..0x2dac7` then calls the three denoise GRUs in order. | 256 noise values followed by 10,240 convolution values feed the 10,496-input GRU; subsequent widths are 256, 512, 1,024. |
| Recurrent cell and direction | `0x2bdff..0x2be18` supplies mode 3 (GRU), direction 0 (unidirectional), input mode 0 (linear), and one layer to the RNN descriptor. | Four independent stateful reset-after GRUs, without bidirectional summation, stacked hidden state sharing, or skipped input matrices. |
| Recurrent matrix and bias blocks | `0x2c210..0x2c483` iterates linear-layer IDs 0 through 5. IDs below 3 copy successive input-weight blocks; IDs 3 through 5 copy successive recurrent-weight blocks. Biases copy successive hidden-width blocks using the same ID. | Input/recurrent matrices retain row-major output-by-input storage. Input reset/update/new biases precede recurrent reset/update/new biases. The reset scales the recurrent candidate projection and its bias. |
| Initial and subsequent state | `0x2c003..0x2c029` clears the initial hidden buffer; `0x2b725..0x2bd52` supplies retained state to recurrent inference. | Hidden vectors start at zero, persist between frames, and reset explicitly. Clearwave commits a frame's candidate states only after validating the final mask. |
| Final dense projection | `0x2d6c5..0x2d6e1`, `0x29294..0x2929e`, and `0x29c18..0x29c5b`; bias is added at `0x29cb4..0x29cdc`, activation mode 0 is selected at `0x2938d..0x2939e`, and activation follows bias at `0x29ce1..0x29d42`; see `OUTPUT_PROJECTION.md`. | Stored input-major `[1024,961]` is transposed once at setup, followed by the output bias and sigmoid. |

The cuDNN mapping uses the documented [row-major recurrent matrix convention](https://docs.nvidia.com/deeplearning/cudnn/archives/cudnn-860/api/)
and [GRU linear-layer IDs](https://docs.nvidia.com/deeplearning/cudnn/backend/v9.18.1/api/cudnn-adv-library.html).
These API descriptions interpret the runtime's descriptor and loading calls;
they are not a substitute for tracing those calls.

## Implementation boundaries and validation

The graph has no unresolved learned-layer connection, stored tensor axis, gate
order, bias order, activation placement, or hidden-state operation within this
supported feature contract. CPU and resident GPU execution share graph dimensions
and parameter ordering. The GPU concatenation receives dimensions through its
uniform parameters rather than embedding model widths in the shader.

Regression fixtures use asymmetric dimensions and distinct values to distinguish
frequency/channel order, input-major projection, all GRU gates, and all six bias
blocks. The operator command also checks the resident graph, state reset,
rejected-context state preservation, and the asymmetric GPU concatenation.
At graph completion, all 38 Rust unit tests passed. The later waveform-startup
correction and its 39-test suite are described in `AUDIO_ALIGNMENT.md`. All 30 local AMD operator/graph checks passed. The graph-only public speech regression in `model-graph-speech-check.json`,
which predates that waveform-startup correction, confirms byte-identical output to the corrected 0.6.6 graph for two clean voices and the same two voices mixed with static, hum, and clicks. Those checks validate the implementation; they contribute no implementation
percentage. Current numerical results are recorded separately in
`model-graph-check.json`.

The waveform adapter's feature scaling, startup/flush policy, and agreement with
running vendor output remain a separate milestone. A complete feature graph also
does not establish speech enhancement, subjective voice quality, or recovery of
speech detail missing from an input recording.
